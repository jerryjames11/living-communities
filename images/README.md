# Image slots

Drop your photos into this `images/` folder using these exact filenames.
The site already works without them — every slot shows a clean placeholder
box (with a filename label on the larger ones) until the real file exists,
so nothing looks broken in the meantime. As soon as a file lands here under
its matching name, it just appears — no code changes needed.

Recommended sizes are a guide, not a hard requirement (the boxes crop to
fill via `object-fit: cover`).

## Dashboards (homeowner + provider)

| Filename | Used for | Suggested size |
|---|---|---|
| `dashboard-welcome.jpg` | Welcome banner photo, both dashboards | 500×300 |
| `avatar-homeowner.jpg` | Fallback avatar photo for homeowner accounts (initials show until this exists) | 200×200 |
| `avatar-provider.jpg` | Fallback avatar photo for provider accounts (initials show until this exists) | 200×200 |
| `service-lawn.jpg` | "Popular Services" tile / request thumbnails — Lawn & Landscaping | 500×375 |
| `service-handyman.jpg` | Same, for Handyman requests | 500×375 |
| `service-pool.jpg` | Same, for Pool Service requests | 500×375 |
| `service-pest.jpg` | Same, for Pest Control requests | 500×375 |

Note: `service-plumbing.jpg`, `service-electrical.jpg`, `service-hvac.jpg`,
and `service-cleaning.jpg` are reused inside the dashboards too (on request/
quote/job/lead cards), so you don't need separate copies for those four.
